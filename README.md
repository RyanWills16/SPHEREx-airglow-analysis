# SPHEREx-airglow-analysis
Repository for code used in analyzing airglow measurements made by The Spectro-Photometer for the History of the Universe, Epoch of Reionization and Ices Explorer (SPHEREx). This relates to work submitted to JRG: Atmospheres. See https://arxiv.org/abs/2605.00851 or https://doi.org/10.22541/essoar.15002513/v1 for preprint
